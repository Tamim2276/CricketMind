\begin{abstract}
Cricket analytics systems typically serve one audience with one task, and report numbers they never check. We present CricketMind, an agentic architecture that turns a batting-shot clip, or a text-only question, into a stakeholder-specific report in which every cited figure is verified. Two sanctioned engines, a statistics engine and a Monte Carlo what-if simulator, are the only components permitted to produce numbers. A supervisor router activates a subset of twelve stakeholder agents, and a faithfulness gate compares every figure an agent cites with the engines' values, regenerating failing agents within a bounded budget and withholding findings that still fail. We evaluate a reference implementation built as a LangGraph state graph whose components are deterministic stand-ins, apart from the router. Its cost follows a closed-form model that predicts the measured superstep count of seven scenarios exactly, with a worst case of 29 supersteps fixed when the graph is constructed. On paraphrased queries that avoid every routing keyword, a keyword router activated the intended agent for none of twelve queries, while a locally hosted 7B language-model router activated it for nine, with identical decisions across three runs. Because fixed rules follow the router's proposal, the architecture's bounds hold for either router.
\end{abstract}
